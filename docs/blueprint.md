# **App Name**: VidyaSphere Clone

## Core Features:

- Homepage: Display the landing page with the title, subtitle and the call to action button.
- Play Games Button: Redirect the user to the games page when clicking on this button
- Header Logo: Place the logo with the app's name in the header
- Globe Icon: Include a globe icon that when pressed does nothing for now.

## Style Guidelines:

- Primary color: Soft purple (#A37BFF) to evoke a sense of creativity and intelligence, fitting for a STEM-focused platform.
- Background color: Light gray (#F7F7FF) to provide a clean, distraction-free backdrop.
- Accent color: Slightly darker purple (#9466FF) used for the button to highlight call-to-action.
- Font: 'Poppins' sans-serif font for both headlines and body text to provide a modern and approachable feel.
- Use simple, flat icons relevant to education and games.
- Keep the layout clean and centered, ensuring the focus remains on the headline and the call-to-action.
- Add a subtle hover effect to the button for visual feedback.
