# Contributing to VidyaSphere

Thank you for your interest in contributing to VidyaSphere.

VidyaSphere is a source-available educational platform maintained by Vivek Vishwakarma. Contributions are welcome, but all contributions must follow the project rules and license.

## Before You Start

Before working on an issue:

1. Read the issue completely.
2. Comment on the issue if you intend to work on it.
3. Wait for maintainer confirmation for major features or architectural changes.
4. Do not start large changes without discussion.

## How to Contribute

1. Fork the repository.
2. Create a dedicated branch.
3. Make your changes.
4. Add or update tests where applicable.
5. Verify that the project builds successfully.
6. Commit your changes with a clear commit message.
7. Push your branch to your fork.
8. Open a Pull Request against the official `main` branch.

## Branch Naming

Use descriptive branch names:

- `feat/<feature-name>`
- `fix/<bug-name>`
- `docs/<change-name>`
- `refactor/<change-name>`
- `test/<change-name>`
- `chore/<change-name>`

Examples:

`feat/offline-sync`

`fix/teacher-dashboard`

`docs/contributing-guide`

## Pull Request Requirements

Every Pull Request should:

- Explain what was changed.
- Explain why the change was needed.
- Reference the related issue.
- Include tests where applicable.
- Avoid unrelated changes.
- Keep commits focused and understandable.
- Avoid introducing secrets, credentials, API keys, passwords, or personal data.

## Architecture Changes

Changes affecting the following areas require maintainer review before implementation:

- System architecture
- Database schema
- Offline synchronization
- Authentication
- Authorization
- AI architecture
- Simulation engine
- Gamification engine
- Teacher dashboard architecture

## Contribution Rights

By submitting a Pull Request or other contribution to VidyaSphere, you confirm that:

1. You have the legal right to submit the contribution.
2. Your contribution does not knowingly violate another person's intellectual property rights.
3. You grant the VidyaSphere project maintainer a non-exclusive, worldwide, royalty-free right to use, modify, integrate, reproduce, and distribute your contribution as part of VidyaSphere.
4. The contribution may be modified, combined with other code, or included in future versions of VidyaSphere.

This contribution permission does not transfer ownership of your pre-existing independent work to the project maintainer.

## Ownership and Project Control

VidyaSphere remains controlled and maintained by Vivek Vishwakarma.

Contributors do not automatically become owners, maintainers, or authorized representatives of the official VidyaSphere project.

Only the official repository maintained by the project owner is considered an official VidyaSphere release.

## Code Review

All Pull Requests are subject to review.

The maintainer may:

- request changes;
- reject a Pull Request;
- merge a Pull Request;
- close a Pull Request without merging.

Submitting a Pull Request does not guarantee acceptance.

## Prohibited Contributions

Do not submit:

- API keys
- passwords
- private credentials
- malware
- copyrighted material without permission
- confidential information
- personal data
- code copied from incompatible licenses

## Questions

For questions about architecture or contribution scope, open a GitHub Issue or Discussion before starting significant work.
